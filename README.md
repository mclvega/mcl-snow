# McL Snow

Shooter en primera persona por equipos para el navegador, inspirado en el mapa fy_snow de Counter-Strike 1.6. Eres antiterrorista y juegas con bots aliados contra bots terroristas. Las rondas no se acaban y cada vez hay más enemigos.

- Hay 4 armas: rifle AK, AWP con mira, Deagle y cuchillo. Los disparos a la cabeza hacen ×4 de daño.
- Incluye radar, registro de bajas, marcador y tiempo de ronda.
- Los personajes son avatares 3D como los del Arcade, y el tuyo se personaliza en «Personaje».
- Se controla con ratón y teclado, mando o pantalla táctil (joystick, arrastrar para mirar y apuntado asistido).
- Hay 4 dificultades y pantalla completa por defecto.

## Ejecutar

```sh
npm install
npm run dev      # http://localhost:5173/?demo empieza una partida directamente
npm test
npm run build
```
